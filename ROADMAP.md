# Roadmap

- [x] Date-range backfill with resumable client continuation
- [x] Multi-cat activity and duration charts
- [x] Explicit inference uncertainty and manual correction
- [x] Portable deployment and synthetic regression tests
- [x] Publish the public GitHub repository and verify hosted CI
- [ ] Validate T3 and camera-model pagination with volunteer-owned hardware
- [ ] Separate training and display windows; cap supervised validation cost
- [ ] Opt-in sanitized diagnostic export and documented retention/deletion
- [x] Interactive demo with synthetic data and page-local labels
- [x] Export displayed records as CSV with explicit scope and classification provenance
- [ ] OAuth integration for clients that cannot send a static bearer token

Physical device actions and medical diagnoses are out of scope.
